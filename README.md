# TypeScript & OOP Assignment

## Assignment Overview

This repository contains my solutions for the **Problem Solving with
TypeScript & OOP** assignment. The assignment focuses on building a
strong understanding of TypeScript fundamentals, advanced types,
generics, asynchronous programming, and Object-Oriented Programming
(OOP).

## Topics Covered

-   TypeScript Basic Types
-   Optional and Default Parameters
-   Rest Parameters
-   Union Types and Type Narrowing
-   Readonly Tuples
-   Interfaces
-   Generics and Keyof Constraints
-   Promises and Async/Await
-   Object-Oriented Programming (OOP)
-   Classes, Inheritance, and Access Modifiers
-   TypeScript Compilation and Configuration

## How to Run

### 1. Install TypeScript

``` bash
npm install -g typescript
```

### 2. Compile the TypeScript file

``` bash
tsc solutions.ts
```

### 3. Run the generated JavaScript file

``` bash
node solutions.js
```
